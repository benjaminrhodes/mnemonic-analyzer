# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to the maintainers. We aim to respond within 48 hours.

Do NOT create public GitHub issues for security vulnerabilities.

## Security Considerations

- This tool uses synthetic data only for testing
- No sensitive data is stored or transmitted
- All computation is performed locally
